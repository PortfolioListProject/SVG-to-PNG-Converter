# Image-to-PNG-Converter
Converts SVG and WEBP to PNG using Python

# Requirements 
- you need cairosvg as it has a better SVG Rendering and you would need gtk3-runtime-3.24.31-2022-01-04-ts-win64.exe 
so download it from https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer/releases
afterward you should run pip install cairosvg in the terminal and then you should be fine
- you also need to run pip install Pillow in your terminal for the Webp converter
